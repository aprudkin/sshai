Удалённое выполнение без переполнения контекста

Запускайте удалённо. Держите доказательства локально.

sshai выполняет уже авторизованные неинтерактивные команды через системный клиент OpenSSH, сохраняет полученный вывод локально и возвращает агенту ограниченный результат.

Граница

Транспорт и доказательства отделены от операционных полномочий. sshai не предоставляет прав на доступ к хосту или изменение его состояния.

01 / Один ограниченный путь

От выбранного алиаса до компактного результата

Этот CSS-макет с карточками сохраняет читаемость каждого шага выполнения без горизонтальной прокрутки.

02 / Доказательства по запросу

Полный результат доступен, но не воспроизводится по умолчанию.

Локальные артефакты позволяют запросить нужный фрагмент вместо повторной загрузки большого вывода команд в контекст агента.

Возвращается сразу

Ограниченный паспорт или JSON

После сохранения формируются исход, расположение артефакта и компактная сводка доказательств. Для распознанных сбоев SSH возвращается только каноническая очищенная транспортная диагностика.

Выбирается позже

Запросы к локальным доказательствам

Запрашивайте фрагмент, полезный для текущего расследования, и сохраняйте полученный артефакт как первичный источник.

qdifflog--delta

03 / Ограничения остаются явными

CLI сохраняет значимые исходы, а не скрывает их.

Отказ политики, транспортный сбой и ненулевой код завершения удалённой команды — разные результаты. Это различие входит в контракт доказательств.

Настроенные идентификаторы

Используйте существующую SSH-конфигурацию

Алиасы, конфигурация OpenSSH и локальный процесс авторизации остаются за пределами области ответственности инструмента.

Явный отказ

Отказывайте неподдерживаемым путям выполнения

Интерактивные программы, секреты в stdin, разовые параметры идентификации, передача файлов и неподдерживаемое двухпереходное выполнение требуют другого утверждённого процесса.

Выбор удалённой оболочки

Используйте нужную оболочку Windows

PowerShell 7 используется по умолчанию. Выбирайте Windows PowerShell 5.1 явно только когда это требуется команде.
