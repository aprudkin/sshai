Remote command execution, without context flooding

Run remotely. Keep evidence local.

sshai runs already-authorized, non-interactive commands through the system OpenSSH client, stores captured output locally, and returns a bounded result to the agent.

The boundary

Transport and evidence are separate from operational authority. sshai does not grant permission to access or change a host.

03 / Guardrails stay explicit

The CLI preserves meaningful outcomes instead of hiding them.

Policy denial, transport failure, and a remote non-zero exit are distinct results. That distinction is part of the evidence contract.

Configured identities

Use the existing SSH configuration

Aliases, OpenSSH configuration, and the local authorization process remain outside the tool's scope.

Fail closed

Refuse unsupported execution paths

Interactive programs, secret stdin, ad-hoc identities, file transfer, and unsupported two-hop execution require another approved workflow.

Remote shell choice

Use the intended Windows shell

PowerShell 7 is the default. Select Windows PowerShell 5.1 explicitly only when a command needs it.
