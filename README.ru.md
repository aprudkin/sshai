# sshai

<p align="center"><img src="assets/readme/banner-ru.svg" width="100%" alt="sshai: удалённые команды и компактные доказательства"></p>

`sshai` — CLI на Go для ИИ-агентов, запускающий неинтерактивные команды Linux bash и Windows
PowerShell 7 по SSH. Полученный вывод сохраняется локально, а в контекст агента возвращается
компактный паспорт запуска.

Удалённые команды внутрь. Компактные доказательства наружу.

## Для кого

Используйте `sshai` для уже авторизованных неинтерактивных команд на хостах из `ssh_config`, когда
нужны доказательства без загрузки большого вывода в диалог агента. Инструмент разделяет транспорт,
доказательства и операционные полномочия.

## Возможности

- Запуск на одном или нескольких SSH-алиасах Linux/bash либо Windows/PowerShell 7.
- Локальное хранение вывода и компактный паспорт с исходом и путём к артефакту.
- Запросы, сравнения и поиск по артефактам без повторной загрузки всего результата.
- `--body-file` для многострочных команд, JSON-конверты результатов, `--delta` и именованные
  контексты.
- Явный отказ вместо небезопасного обхода ограничений для интерактивных программ, PowerShell 5.1,
  секретов в stdin, разовых параметров идентификации и неподдерживаемых двухпереходных сценариев.

В ходе выполнения полученный вывод остаётся локальным, а в контекст агента возвращаются только
ограниченные доказательства:

## Быстрый старт

Требуются Go `1.26.5` или новее в ветке `1.26`, OpenSSH и локально настроенный SSH-алиас.

```bash
git clone https://github.com/aprudkin/sshai.git
cd sshai
go test ./...
scripts/install.sh
sshai run web01 -- df -h
```

Не передавайте многострочное тело через аргументы процесса:

```bash
sshai run --body-file check.ps1 win01
```

Для автоматизации используйте версионированный JSON-конверт:

```bash
sshai run --result-format=json web01 -- uname -a
```

Полный список команд — `sshai help`, контракт запуска — `sshai help run`.

## Граница безопасности

`sshai` — инструмент транспорта и доказательств. Он не выдаёт полномочий на доступ к хосту или
изменение его состояния.

- Выполняйте только отдельно авторизованные действия на настроенных алиасах.
- Не передавайте в командах или артефактах пароли, токены, ключи, сертификаты и ожидаемый секретный
  вывод.
- Для многострочных тел используйте `--body-file`; для секретов в stdin и передачи файлов нужен
  отдельный утверждённый процесс.
- Отказ политики, транспортный сбой и ненулевой код завершения удалённой команды — разные исходы.

См. [руководство для агентов](docs/agent-usage.md) с правилами использования по умолчанию и
резервными путями.

## Статус проекта и бенчмарки

### Статус проекта

Версия 1 включает `run`, `q`, `diff`, `log`, `hosts`, `gc` и `help`; результаты приёмки Linux и
Windows сохранены в репозитории.

### Контролируемый бенчмарк v1.1

Контролируемый бенчмарк v1.1 завершён 13 августа 2026 года: 36 наблюдений без изменений на двух
хостах Linux и одном хосте Windows в новых Codex-сессиях для прямого SSH и `sshai`.

| Метрика | Прямой SSH | `sshai` | Результат |
| --- | ---: | ---: | ---: |
| Видимый агенту помеченный вывод, всего оценочных токенов | 855,806 | 1,227 | **меньше на 99.86%** |
| Видимый агенту помеченный вывод, p95 оценочных токенов | 262,152 | 50 | **меньше на 99.98%** |
| Фактические входные токены Codex | 2,896,077 | 1,601,293 | **меньше на 44.71%** |
| Успешные наблюдения | 34 / 36 | 34 / 36 | одинаково (94.44%) |

Цели по p95, компактизации контекста, успешности и отладке экранирования достигнуты. Основная цель —
сократить фактические входные токены хотя бы на 80% — не достигнута, поэтому зафиксированный итог —
**needs work**, а не подтверждённый результат. Подробности и ограничения приведены в
[полном отчёте](docs/benchmarks/v1.1-results-2026-08-13.md).

### Рабочий сбор в продакшене

Отдельный обезличенный рабочий прогон 25 августа 2026 года использовал `sshai` как основной контур
управления для согласованного PCI DSS-сбора на 79 Windows-серверах. В ходе сбора получено 158
исходных файлов отчётов; архивы выгружались отдельно, и SHA-256 каждого полученного архива совпал
со значением, сообщённым источником.

| Продакшен-измерение | Байты | Оценка контекста |
| --- | ---: | ---: |
| Полный набор из 158 файлов отчётов | 8,123,158 | ~2.03M токенов |
| Видимый агенту поток управления, статусов и квитанций | 49,846 | ~12.5K токенов |

Поток управления составлял 0.61% от объёма исходных доказательств — примерно в **163 раза меньше**,
то есть на **99.39% меньше байтов**, видимых во время оркестрации.

Это данные реального процесса, а не контролируемый сравнительный бенчмарк потребления токенов.
Оценка вычислена как `ceil(bytes / 4)`; в прогоне понадобились узкие обращения к прямому SSH для
принятия новых ключей хостов и прямого маршрута.
